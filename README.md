# 토몽이와 이지의 방

스트리머 서이지를 위한 수박 게임 스타일의 팬 게임입니다. 구름 가구를 떨어뜨려 같은 가구끼리 합치면 다음 단계 가구가 되고, 11단계 '구름 침대'까지 키우는 게임입니다.

## 플레이

- 바로 플레이: https://audioaudio.github.io/eztomong/
- 마우스로 위치를 정하고 클릭하면 떨어뜨립니다. 키보드는 ← → 로 이동, Space/Enter 로 떨어뜨리기, Esc 로 일시정지입니다.
- 화면은 1280×720 (16:9) 기준이고, 창 크기에 맞춰 자동으로 커지고 작아집니다. 방송 화면(OBS 브라우저 소스)에도 그대로 쓸 수 있습니다.

## 화면

타이틀 · 게임 · 일시정지 · 게임 종료/랭킹 등록 · 도감 · 랭킹 · 옵션 (배경음악·효과음·드롭 가이드선·기록 초기화)

## 저장

최고 점수, 도감, 랭킹, 옵션은 브라우저(localStorage)에 저장됩니다. 서버로 보내지 않습니다.

## 파일

- `index.html`: 게임 전체 (스크립트·스타일 포함). 물리 엔진 Matter.js 0.19 는 cdnjs 에서 불러옵니다.
- `assets/`: 그림·사운드

로컬에서 열 때는 `index.html` 을 바로 열어도 되지만, 일부 브라우저는 파일 직접 열기에서 이미지 읽기가 제한되므로 간단한 웹 서버를 권장합니다 (예: `python3 -m http.server`).
